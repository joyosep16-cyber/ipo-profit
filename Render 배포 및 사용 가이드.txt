✅ Neon PostgreSQL 클라우드 데이터베이스 사용
   - 영구적으로 데이터 유지됨 (자동 백업)
   - PC 켜지 않아도 24시간 접속 가능
   - 모바일에서 저장한 데이터 = PC에서도 동일
   - 무료로 영구 사용 가능 (무제한)
   - 로컬 PC와 클라우드 자동 동기화


─────────────────────────────────────────
[ 로컬 PC에서도 사용하기 (데이터 동기화) ]
─────────────────────────────────────────

같은 데이터베이스(Neon PostgreSQL)를 사용하면
로컬과 클라우드의 데이터가 자동 동기화됩니다.

[1단계] .env 파일 생성
  1. .env.example 파일을 복사
  2. 파일명을 ".env" 로 변경
  3. 텍스트 편집기로 열기

[2단계] DATABASE_URL 설정
  .env 파일에서 DATABASE_URL 값을 다음과 같이 설정:

  NEON_DATABASE_URL=postgresql://neondb_owner:비밀번호@ep-cool-boat.ap-southeast-1.aws.neon.tech/neondb?sslmode=require

  (실제 Neon 연결 정보로 교체)

[3단계] 로컬 앱 실행
  공모주앱 실행.bat 파일을 더블클릭
  → http://localhost:8501 에서 실행됨

또는

[설정 페이지 이용]
  1. 공모주앱 실행.bat 실행
  2. 설정 → 🔄 데이터 동기화 섹션
  3. ✅ 클라우드 데이터 동기화 활성화 체크
  4. 💾 설정 저장 → 앱 자동 재시작

결과:
  - 로컬에서 저장 → 클라우드에서도 조회 가능
  - 모바일에서 저장 → 로컬에서도 조회 가능
  - 모든 기기에서 동일한 데이터 사용!


─────────────────────────────────────────
[ 코드 수정 후 배포 ]
─────────────────────────────────────────

코드 수정 후 GitHub에 push하면 자동으로 배포됩니다.

[1단계] 로컬 PC에서 코드 수정

  예: app.py, pages/watchlist.py 등 파일 편집

[2단계] GitHub에 업로드

  CMD 창을 열고 프로젝트 폴더에서:

  cd "c:\Users\ADMIN\OneDrive\바탕 화면\IPO Subscription Profit"

  git add .
  git commit -m "수정 내용 (예: 버그 수정)"
  git push

[3단계] 자동 배포 시작
  - GitHub에 업로드되면 Render가 자동으로 감지
  - 자동으로 빌드 시작 (3~5분 소요)
  - 완료되면 https://ipo-profit-app.onrender.com 에 자동 반영

─────────────────────────────────────────
[ 자동 배포 예시 ]
─────────────────────────────────────────

예시 1: 버그 수정
  1. watchlist.py에서 버그 수정
  2. git add . && git commit -m "fix: 관심 목록 버그 수정" && git push
  3. 3~5분 후 자동으로 Render 반영됨
  4. 모든 사용자가 자동으로 최신 버전 사용

예시 2: 새 기능 추가
  1. 새로운 함수/기능 코드 작성
  2. git add . && git commit -m "feat: 새 기능 추가" && git push
  3. 자동 배포 → 즉시 서비스에 반영됨


─────────────────────────────────────────
[ 주의사항 ]
─────────────────────────────────────────

⚠️ Render 무료 플랜 특성:

1. 비활성 중지
   - 15분 동안 요청이 없으면 앱이 자동 일시 중지됨
   - 다시 접속하면 자동 재시작됨
   - 첫 접속 시 약 50초 정도 걸릴 수 있음
   - 이후 정상 속도로 작동함

2. Neon 무료 플랜
   - 영구 무료 제공
   - 데이터 무제한 저장
   - 비활성 중지 없음 (데이터베이스는 항상 살아있음)
