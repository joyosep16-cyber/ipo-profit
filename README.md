# 📈 공모주 분석 & 수익 관리 앱

IPO(신규상장주식)의 **청약 전 수요예측 점수 분석**부터 **청약 후 수익 관리**까지
전 주기를 브라우저에서 관리하는 Streamlit 기반 웹 앱입니다.

> 🔍 **공모주 분석** 엔진 통합: 38커뮤니케이션 수요예측 결과 + DART 공식 공시 교차검증으로
> 기관 경쟁률·의무보유확약·유통가능규모·장외 괴리율을 점수화하여 청약 여부를 판단합니다.

## 🚀 빠른 시작

### 설치 및 실행
```bash
# 1. 초기 설치 (첫 실행 시만)
더블클릭: 설치.bat

# 2. 앱 실행
더블클릭: 공모주앱 실행.bat
```

- 브라우저가 자동으로 열리며 `http://localhost:8501` 에서 접속됩니다.
- 종료: 명령 창을 닫거나 작업 관리자에서 python.exe 프로세스 종료

## ✨ 주요 기능

### 🔍 공모주 분석 (신규)
- 38커뮤니케이션 수요예측 결과 크롤링 + **DART 공식 공시 교차검증**
- 핵심 산식을 원본 수량으로 직접 계산:
  - 기관 경쟁률 = 기관 총 신청수량 / 기관 배정물량
  - 의무보유확약 비율 = (15일~6개월 확약 수량 합계) / 기관 총 신청수량 × 100
  - 유통가능규모 = 유통가능주식수 × 확정공모가
  - 장외 괴리율 = (장외 절미평균가 − 확정공모가) / 확정공모가 × 100
- 가이드 스코어링(총점/추천 등급)으로 **청약 여부 판단**
- 데이터 신뢰도 표기: 🟢 일치 / 🟡 DART 보정 / 🔴 38 폴백(추정)
- 주관사별 최소 증거금 자동 계산
- **청약 예정 + 상장 대기 종목만 표시** (이미 상장된 종목 자동 제외)
- **스팩(SPAC)/리츠(REIT) 종목 자동 제외** (일반 공모주와 성격이 달라 분석 대상 아님)
- 16점 이상 종목은 매일 14·15·16·17시 Discord 자동 알림
- '관심목록에 추가' 버튼으로 점수와 함께 관심 목록 등록

### 📊 수익 현황
- 청약 기록 조회 및 관리
- 월간/연간 목표 달성률 표시
- 종목별 상세 정보 (청약일, 수익률, 메모 등)
- 엑셀 내보내기/가져오기

### ⭐ 관심 목록
- ipostock.co.kr에서 **자동 조회** (확정가 우선)
- 청약 예정 종목 사전 등록
- D-day 계산 및 자동 알림
- 청약 신청 시 정보 자동 채우기

### 📅 데이터 입력
- **수동 입력**: 모든 정보를 직접 입력
- **엑셀 업로드**: 대량 데이터 한 번에 입력
- 청약일 범위 지원 (2026년 5월 11일~2026년 5월 12일)
- 자동 수익률 계산

### 📉 통계 & 차트
- 월별 수익 막대 차트
- 증권사별 수익 비중 도넛 차트
- 청약방식별 수익 비교
- 누적 수익 추이 라인 차트
- 분기별 성과 비교

### ⚙️ 설정
- **Discord 알림**: 새 종목 추가, 고수익 달성, 월간 요약, 공모주 분석 자동알림 등
- **DART API 키**: OpenDART 무료 키 입력 시 수요예측 수량 공식 공시 교차검증
- **분석 자동알림**: 임계점(기본 16점)·on/off 설정
- **모바일 외부 접속**: ngrok으로 외부 공개 URL 생성
- **목표 수익**: 월간/연간 목표 설정 및 진행률 표시

## 📊 데이터 구조

### IPO Record (공모주 기록)
```
- 청약일 (범위): 2026년 5월 11일~2026년 5월 12일
- 종목명: 삼성스팩
- 증권사: 미래에셋증권
- 공모가: 12,000원
- 청약방식: 균등 / 비례
- 당첨여부: 당첨 / 미당첨
- 수량: 10주
- 상장일: 2026년 5월 20일
- 매도가: 15,000원
- 수익: 30,000원 (수익 = (매도가 - 공모가) × 수량)
- 수익률: 25% (수익 / 공모가 / 수량 × 100)
- 메모: 자동 라벨 또는 사용자 입력
```
