■ 로컬 앱 실행 방법
──────────────────────────────────────────────────────────

  [1단계] 초기 설치 (처음 한 번만)
    설치.bat 파일을 더블클릭
    → Python 패키지 자동 설치

  [2단계] 데이터베이스 선택 (선택사항)

    ⚙️ 설정 페이지 이용:
    ① 공모주앱 실행.bat 실행
    ② 설정 → 🔄 데이터 동기화 섹션
    ③ 체크박스로 ON/OFF 선택:
       - ✅ ON: Neon PostgreSQL 사용 (클라우드 동기화)
       - ☐ OFF: 로컬 SQLite 사용 (이 PC에만 저장)
    ④ 💾 설정 저장 → 앱 자동 재시작

    또는

    .env 파일 직접 설정:
    ① .env.example 파일을 복사해서 .env 로 저장
    ② .env 파일을 텍스트 편집기로 열기
    ③ NEON_DATABASE_URL 값 입력:
       NEON_DATABASE_URL=postgresql://neondb_owner:비밀번호@ep-xxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require

    ※ .env 파일이 없으면 로컬 SQLite(data/ipo.db) 자동 사용
    ※ .env 파일 설정 후 설정 페이지에서 ✅ 활성화하면 PostgreSQL 사용

  [3단계] 앱 실행
    공모주앱 실행.bat 파일을 더블클릭
    → 명령 창이 열리고 http://localhost:8501 에서 앱 실행
    → 브라우저가 자동으로 열림

  [4단계] 앱 종료
    설정 → 🛑 앱 종료 버튼 클릭
    또는 명령 창을 닫거나 작업 관리자에서 python.exe 종료

  ※ 초기 설치 시 설치.bat 를 먼저 실행해 패키지를 설치하세요.
  ※ 데이터는 Neon PostgreSQL (클라우드) 또는 data/ipo.db (로컬 SQLite) 에 저장됩니다.
  ※ 앱이 실행 중인 동안 스케줄러(자동 알림)도 함께 동작합니다.
  ※ 달력(날짜 선택) UI는 자동으로 한국어로 표시됩니다.
  ※ 월간 요약 알림: 매월 1일 오전 9시 (로컬/클라우드 모두)

══════════════════════════════════════════════════════════
  ⭐ 관심 목록 (청약 예정 종목 관리)
══════════════════════════════════════════════════════════

  청약 예정 공모주를 사전에 등록해 두는 기능입니다.

  [➕ 관심 종목 추가] 접이기 클릭 → 두 가지 입력 방식 선택:

  [🔍 자동 조회] — ipostock.co.kr에서 자동으로 정보 가져오기
    ① 종목명 입력 후 [🔍 조회] 클릭
    ② 확정 공모가 (또는 희망가) · 청약일 · 상장일 · 증권사가 자동으로 채워짐
    ③ 필요하면 내용 수정 후 [💾 저장]

    ※ 현재 청약 중인 종목과 수요예측 단계 종목 모두 지원
    ※ 정보를 찾을 수 없으면 수동 입력 모드로 전환

  [✏️ 수동 입력] — 직접 모든 정보를 입력
    📌 종목명      — 필수
    🏦 증권사      — "미정" 선택 가능 (미결정 시 사용)
    📅 청약 시작일 — 선택 (범위 지원: YYYY년 MM월 DD일 ~ ...)
    📅 청약 종료일 — 선택 (D-day 계산 기준)
    🏛️ 상장일      — 선택 (청약 신청 시 입력 화면에 자동 채움)
    💰 공모가      — 선택 (영향도 높음: 청약 신청 시 기본값 사용)
    📝 메모        — 선택

  목록에서 D-day 표시:
    D-N    — 청약 종료일까지 N일 남음
    D-Day  — 오늘이 청약 마감일
    종료   — 청약 기간 종료
    -      — 청약 종료일 미입력

  상태 표시:
    (표시 없음)   — 관심 (청약 전)
    🟢 청약완료  — 청약 신청 후 저장 완료
    🔴 미신청    — 청약 종료일이 지났으나 청약하지 않음
                   (매일 자정 자동으로 상태 변경됨)

  [✅ 청약 신청] 버튼:
    클릭하면 데이터 입력 화면으로 이동하며
    종목명·청약 종료일·공모가·증권사·상장일이 자동으로 채워집니다.
    저장 완료 시 관심 목록 상태가 '청약완료'로 자동 변경됩니다.

  🔍 공모주 분석 (청약 전 점수 분석)
══════════════════════════════════════════════════════════

  38커뮤니케이션 수요예측 결과와 DART 공식 공시를 교차검증하여
  종목별 점수를 매기고 '청약 여부'를 판단해 주는 화면입니다.

  [청약일정 목록]
    - 현재 청약 예정 + 상장 대기 종목이 목록으로 표시됩니다.
    - 이미 상장된 종목과 스팩(SPAC)/리츠(REIT)는 자동으로 제외됩니다.
    - 종목 선택 후 [📊 분석 실행] → 점수 카드 표시

  [직접 검색]
    - 종목명 또는 38커뮤니케이션 고유번호(no)로 직접 분석

  [분석 결과 카드]
    🎯 종목명 / 청약일정 / 상장일
    📊 분석점수 (0~16점, 16점 이상 = 🟢 추천)
    🔴 데이터 품질 (DART API 사용 여부)
    💰 장외 프리미엄 (선물 시장 현황)
    ✅ 기여도 높은 기업 (의무보유확약 여부)

  [📌 관심목록 추가 & 🚀 Discord 발송]
    - 분석 결과를 관심 목록에 바로 추가
    - Discord에 분석 점수 카드 자동 발송


══════════════════════════════════════════════════════════
  ✏️ 데이터 입력 (공모주 기록 관리)
══════════════════════════════════════════════════════════

  [수동 입력 탭]

  왼쪽 입력 항목:
    📅 청약 시작일 — 청약 기간의 시작 날짜 (선택)
    📅 청약 종료일 — 청약한 날짜 / 청약 기간 종료일 (기본값: 오늘)
                    표시: YYYY년 MM월 DD일 ~ YYYY년 MM월 DD일
    📌 종목명     — 필수 입력
    🏦 증권사     — 목록에서 선택
    💰 공모가     — 청약 공모 가격 (필수 입력)

  오른쪽 입력 항목:
    📋 청약방식  — 균등 / 비례 선택
    🎯 당첨 여부 — 당첨 / 미당첨 선택 (미당첨 시 아래 필드 비활성화)
    📦 수량     — 배정받은 주수
    🏛️ 상장일   — 상장(매도)한 날짜 (선택 입력)
    💲 매도가   — 실제 매도 가격 (입력 시 수익 자동계산)
    📝 메모     — 자유 입력 (비워두면 수익률 기준 자동 라벨 적용)

  ※ 공모가·수량·매도가를 모두 입력하면 총수익·수익률·투자원금이
     실시간으로 미리보기됩니다.
  ※ 매도가를 입력하지 않아도 저장 가능합니다 (나중에 수정 가능).

  메모 자동 라벨 기준 (수익률):
    수익률 300% 이상 → 🚀 초고수익
    수익률 200% 이상 → 🎉 고수익
    수익률 100% 이상 → ✨ 우수
    수익률  50% 이상 → 👍 양호
    수익률   0% 초과 → 📈 수익
    수익률   0%      → ➖ 손익없음
    수익률 음수      → 📉 손실
    매도가 미입력    → ➖ 매도 미입력
    미당첨           → ❌ 미당첨

  [엑셀 업로드 탭]

  '수익 현황' 화면에서 다운로드한 엑셀 파일을 양식으로 사용합니다.

  엑셀 컬럼 구성 (순서):
    청약일 / 종목명 / 증권사 / 공모가 / 청약방식 / 당첨 여부 /
    상장일 / 매도가 / 수익 / 수량 / 수익률(%) / 메모

  필수 컬럼: 청약일, 종목명, 공모가
  선택 컬럼: 나머지 (없으면 기본값 적용)


══════════════════════════════════════════════════════════
  📊 수익 현황 (메인 화면)
══════════════════════════════════════════════════════════

  상단: 연도 필터 (전체 / 연도별 선택)
  중간: 등록된 종목 테이블
  하단: 수익 요약 지표

  컬럼 설명:
    청약일  — 공모주를 청약한 날짜
    상장일  — 상장(매도)한 날짜
    종목    — 종목명
    증권사  — 청약한 증권사
    공모가  — 청약 시 공모 가격
    매도가  — 실제 매도한 가격 (미입력 시 -)
    청약    — 균등 / 비례
    당첨    — 당첨 / 미당첨
    총수익  — (매도가 - 공모가) × 수량
    수량    — 배정받은 주식 수
    수익률  — 수익 / 투자원금 × 100 (%)
    메모    — 자동 라벨 또는 직접 입력한 메모

  하단 요약 지표:
    합계        — 필터된 종목들의 총수익 합산
    종목 수     — 필터된 종목 수
    평균 수익률 — 매도 완료 종목의 평균 수익률
    승률        — 당첨 종목 중 수익이 발생한 비율

  기능:
    [🔍 상세 필터]     증권사/청약방식/당첨여부/수익률 범위/종목명으로 필터링
    [📥 엑셀 다운로드] 현재 필터된 목록을 엑셀(.xlsx)로 저장
    [+ 새 종목 추가]   데이터 입력 화면으로 이동
    [수정/삭제 선택]   종목 선택 후 수정 또는 삭제

  ⚠️ 경고 메시지:
    당첨 종목 중 청약일로부터 7일 이상 경과했는데 매도가가
    입력되지 않은 종목이 있으면 상단에 경고가 표시됩니다.

    스마트폰 등 외부 기기에서 앱에 접속할 수 있습니다.
    토큰 발급: https://dashboard.ngrok.com/authtokens (무료 계정 가능)
    ※ ngrok URL은 앱 재시작 후 새로 생성됩니다.

  ❓ 자주 묻는 사항 (FAQ)
══════════════════════════════════════════════════════════

  Q. 매도가를 나중에 입력하고 싶어요.
  A. 매도가 없이 저장하면 수익 0으로 기록됩니다.
     수익 현황에서 종목 선택 → [✏️ 수정]으로 나중에 추가하세요.

  Q. 같은 종목을 여러 증권사로 청약했어요.
  A. 증권사별로 별도 항목으로 추가하면 됩니다.

  Q. 관심 목록에서 삭제하면 청약 기록도 사라지나요?
  A. 아닙니다. 관심 목록과 수익 기록은 별개로 관리됩니다.
     관심 목록 삭제는 관심 목록 내 항목만 제거됩니다.

  Q. 로컬과 클라우드의 데이터가 다르게 나와요.
  A. 설정 페이지 → 🔄 데이터 동기화에서:
     - ✅ ON: Neon PostgreSQL 사용 (같은 데이터)
     - ☐ OFF: 로컬 SQLite 사용 (분리된 데이터)

     설정을 확인하고 필요시 변경 후 앱을 재시작하세요.

  Q. 클라우드 URL로 모바일에서 접속했는데 설정이 안 보여요.
  A. 정상입니다. 클라우드 버전은 데이터 동기화 체크박스를 표시하지 않습니다.
     (항상 Neon PostgreSQL 사용)

  Q. 월간 요약 알림이 나오지 않아요.
  A. 로컬 PC 앱이 실행 중이어야 합니다. 또는 클라우드 URL로 접속하면
     매월 1일 오전 9시에 자동으로 발송됩니다 (로컬 실행 불필요).

  Q. 관심 목록에서 자동 조회가 안 돼요.
  A. ipostock.co.kr 사이트 상태를 확인하세요.
     조회 실패 시 수동 입력 모드로 전환하여 직접 입력하면 됩니다.
     이후 종목을 수정할 때 값을 변경할 수 있습니다.

  Q. 달력이 영문으로 표시돼요.
  A. 브라우저를 새로고침하면 한국어로 자동 변환됩니다.
     캐시 문제 시 Ctrl+Shift+Del로 브라우저 캐시를 삭제하세요.

  Q. 수익률이 설정과 다르게 표시돼요.
  A. 분석점수는 DART API 연동 상태에 따라 달라집니다.
     설정 → DART API 키 입력 시 정확도가 향상됩니다.
